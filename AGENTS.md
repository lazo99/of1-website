# of1-website

This is **the** of1.dev site repo. There is no sister "dev" repo.

- `master` = live
- `dev` = development
- Ship by PR: `dev` → `master`

Never create `of1-dev`, `of1-website-dev`, or any second repo for this site.
Never fork this repo for your own workspace. Branch instead.

`lazo99.github.io` is a different, older project (May 2026 first public page). Leave it alone.
